Politique de confidentialité

Dernière mise à jour : 16 octobre 2026.

Qui utilise l'outil

Budget Talk Publisher est un outil personnel. Il est utilisé uniquement par le créateur de la chaîne YouTube Budget Talk, sur son propre ordinateur. Il n'est pas proposé au public.

Données utilisées

Avec l'accord du créateur, l'outil accède à son compte YouTube via les API YouTube de Google, pour :

  • envoyer ses vidéos sur sa chaîne ;
  • renseigner et modifier leurs informations (titre, description, miniature, sous-titres, visibilité) ;
  • lire les statistiques de sa propre chaîne.

Stockage

Les jetons d'accès Google sont enregistrés uniquement sur l'ordinateur du créateur. Aucune donnée n'est envoyée à un serveur tiers, vendue, partagée ou utilisée pour de la publicité.

Utilisation des données Google

L'utilisation des informations reçues des API Google respecte le Règlement sur les données utilisateur dans les services d'API Google, y compris les exigences d'utilisation limitée.

Retirer l'accès

L'accès peut être retiré à tout moment depuis la page Applications tierces ayant accès à votre compte.
